## 仮説

利用枠の参照 API はトークン枠を消費しないため、idle やロック中にポーリングを止める利点は無く、CLI を回したまま離席する使い方では履歴に穴が空くだけである。

## 現状の診断

Agents Pulse は IDLE_PAUSE=300 秒で停止する。Claude Code / Codex CLI を長時間バッチで回す運用では、その間の使用率の推移こそ見たい。

## 採用したときの形

スケジューラは常時動作。スリープ復帰の遅れは灰色の欠測として正直に表示する。

## 反証条件・コスト・リスク

- 参照 API に厳しいレート制限があり 429 が頻発する場合は間隔を伸ばす（design.md v1 は 429 時のみ次回 2 倍）
